## Claim vocabulary

Use only these status words:

- `planned`
- `boundary-fixed`
- `first-floor-evidence`
- `workflow-ready`
- `product-alpha-ready`
- `final-public-ready`
- `production-ready`

## Do not use `100%` casually

`100%` only for externally reproducible workflow or final product/public layer.
