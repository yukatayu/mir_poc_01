各行は、全要件の達成判定ではない。新しい根拠、継承した根拠、残る仕事を区別する。既存Canonと要件表の未承認状態を変更しない。

## AX-01 — 意味を一次資料にする

**元の要求（U）**：システム内部の操作・通信・配置別成果物は、検査済みソースと明示契約から導く。

**今回**：原則を維持し、domain名を含まないsource・構成・現在性の境界を定義した。

**未完**：最終利用領域の十分性・ownerによる採用は未判定。

**接続先**：W1 / W7 / W8。この要件全体を解消する新しい定理はない。

**正例の出口**：同じ意図を異なる配置で実行し、生成辺と結果を元の記述へ対応づける。
**反例の出口**：deploymentが未宣言の操作・辺・権限を追加する候補を拒否する。
