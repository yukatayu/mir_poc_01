# 今回の自走の完了と停止

## 候補としての最終到達点

この作業は、理論監査だけ、READMEだけ、F0.4という名前のモデルだけで完了しない。選択したα profileについて、必要な基礎が証拠で裏付けられ、既存Mir/Mirroreaと接続する実装があり、通常sourceから構築・参加・実network・関係・観測・追加/変更/撤去・復元が一つにつながる候補を目標にする。

α-1～α-8、SC-24を元の要件表から読み、profileに含めた能力の意味を先に確定する。代表的な局所理論、複数認可層、秘密を含む観測、動的構成を、単なる固定値変更・公開値だけ・外部helperだけで代用しない。

全119行は、今回完成/限定達成/後続の義務として理由と根拠を持つ。World-Webの全体、任意の未来理論、任意partitionでの可用性、全engine対応までを、作業終了を不可能にする全称条件へしない。候補完成と、正式なphase受理・公開α・production readyを別々に述べる。

## 少なくとも必要な最終成果

- 採用した意味、型/契約/局所理論の境界、authとpolicy、図式間の関係、更新・復元・観測の統合仕様。
- 宣言的体系に対するchecker/elaboratorの健全性と適切な完全性、実行/合成/更新の保存等、今回依存した主要命題の機械検証とTCB台帳。
- 既存Rust/QUIC等の具体境界との対応表。証明できた範囲と、実装試験／信頼前提に残る範囲を明示。
- 正常動作を拒否しすぎない表現力のコーパス、不正な構成・古い権限・証拠の混同・再送・欠測・更新競合・不完全復元の反例。
- 実network/実storage等の採用profileでの統合利用経路、observer差分／機密差分の対応検査、資源とcleanup。
- 凍結cutのoracleレビューと指摘のdisposition。AIの賛成をproofに数えない。
- fresh再現手順、ログ、hash、Git状態、要件対応、残件、次に作業する層の短い最終報告。

## 途中で成立したら進める

各theory gateが通れば、その保証に依存する実装を進める。まだ実装しない遠期featureの全理論を完成させるまで全作業を停止しない。ただし「未証明を後で付ける」ことを理由に、その命題を前提にしたproduction routeを受理しない。

## 正当な停止

userの停止指示、既存作業との破壊的競合、秘密/production/課金などの未許可操作、L0目的や権限・privacyの弱化、不可逆な未指定意味選択、満たせない署名/認証付き受理、必須toolの実際の利用不能がある場合。

停止前には再開可能なcut、原因、試した代替、できたこと、未達要件、依頼者に必要な最小の判断だけを残す。無関係な作業へ逃げて完了にしない。時間が長いだけ、oracleが静かなだけ、証明が難しいだけ、番号のmilestoneが閉じただけでは停止しない。

理論候補に反例が出たら、失敗を消さず、条件か規則を修正し、元の正例が残ることを確認する。未成立を「パラメータ」と呼んで解決済みにしない。
