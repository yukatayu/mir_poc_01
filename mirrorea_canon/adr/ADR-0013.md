# ADR-0013 -- T0/G0 governance profile と G0 substantive evidence

Decision date: 2026-07-15

Amendment date: 2026-07-28

## Amendment — version 2 profile and fresh artifact

The owner disposition recorded by PROPOSAL-014 is adopted exactly: define
`phase-governance/t0-g0` version 2 with `pass` as its only success literal,
retain the version-1 artifact as nonconforming historical evidence, and permit
one fresh exact version-2 evaluation. The version-1 artifact remains byte-for-
byte historical evidence and is not a valid `fail`, a version-2 artifact, or
eligible evidence for G0-D3 acceptance.

This amendment changes only the current profile version and its one-off
artifact route. It does not reaccept or rebase the G0-D1 evidence cut, its
ordered hashes, the source-hierarchy controls, or the G0-D4 waiver recorded
below. A mismatch of a fixed current control remains `fail` in a valid
version-2 evaluation; no control is repinned to obtain `pass`.

The only version-2 production route is the one fresh ephemeral evaluation at
`LAB:plan/198`, path
`plan/198-t0-g0-governance-profile-v2-evaluation.json`, defined by
`plan/01-phases`. It adds no producer implementation, generator, helper,
schema, CI surface, Make target, or evidence lane. The artifact binds the
amended ADR-0013 blob, profile definition, source revision, fixed evidence,
and self digest. Its direct-child binding is defined by the version-2 profile.

G0-D3 remains **defer**. Neither an artifact result nor this amendment accepts
G0-D3, exits G0, enters T1, authorizes I1, changes an OBL/proof/conformance
state, or makes an additional ADR effective. Any future lifecycle action still
requires its own human acceptance and canonical record.

## 理由

T0 は executable SCN phase ではないが、universal Phase-exit rule の JSON
condition を例外として消すべきでもない。狭い phase-governance profile は、
document/evidence review を semantic proof や implementation conformance と
誤記することなく、必要な structured evidence を残す。D3 を独立して defer
することで、evaluation result と Gate authority を混同しない。

## Original consequences

- `plan/01-phases` が profile の field, checks, result, binding, non-effects を
  定義する。`spec/06-conformance` は SCN-only のままである。
- 既存五 ADR の status / maturity は、この G0-specific acceptance を表すために
  変更しない。
- profile の one-off JSON は LAB evidence であり、program meaning, authority,
  proof, SCN conformance, Gate exit の source ではない。
- exact profile format を変える場合は、通常の canon proposal / human decision /
  ADR / CHANGELOG procedure を再度通す。

## Original rejected alternatives

1. T0 を universal JSON rule の例外にする: lifecycle rule を曖昧にするため採用しない。
2. SCN conformance output を流用する: T0 の document/evidence review を実装適合性に
   偽装するため採用しない。
3. reusable producer を先に実装する: T1 exit までの moratorium と衝突するため採用しない。

## Original reconsideration conditions

profile binding の具体的 drift、accepted evidence の具体的な不整合、又は G0 exit を
実際に適用する owner decision が発生した時に再考する。D3 defer 自体は、G0 exit を
承認する canonical record でのみ置き換えられる。

## Historical version-1 artifact binding

The following is the historical version-1 binding only; it is superseded for
current evaluation by the amendment and `plan/01-phases` version-2 definition.
Let `B` be the commit that first records the single artifact recorded by
`LAB:plan/155`. The evaluated revision must be `B`'s immediate first parent
`C`: `C` descends from the accepted repository evidence cut, contains the
complete ADR-0013/profile-v1/INDEX adoption patch, has a first parent lacking
at least one exact ADR-0013 or profile-v1 blob in `C`, and lacks the artifact
from its own tree. No other revision is valid.
