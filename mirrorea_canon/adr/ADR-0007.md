# ADR-0007 — 順序語彙の principal

**決定**: ソースおよび理論の一次的な順序語彙は、program order・state dependency・send→receive・publish→observe・witness create→use・grant→use・admission 連鎖・cut 順序からなる高水準関係族とする(theory/04)。C++/ISA 流の `memory_order_*` は source principal にせず、model-check の profile 線と実装の写像先に留める。`atomic_cut` を memory fence と再解釈しない。

**理由**: 仮想空間の意味は「誰が何を見てよいか・何が確定したか」であり、fence 語彙で書くと配置透過性と説明可能性を失う。

**再考条件**: OPEN-004 — 実 transport 導入(PHASE-I3)で高水準関係族に表現不能な順序要件が見つかった場合、関係族の追加(置換ではない)を検討。
