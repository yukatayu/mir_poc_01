# ADR-0004 — fallback 単調性と明示的再取得

**決定**: fallback は guarded option chain の後段へ進む操作であり、外側 wrapper へ「戻る」操作ではない。earlier option への暗黙の再昇格は禁止。rollback / atomic_cut は劣化順序を巻き戻さない。復帰(HD 表示へ戻る等)は望ましく頻繁だが、それは**新しい lineage を開始する明示的 reacquire occurrence**(新 witness / 新 epoch)として起きる。

**理由**: 暗黙復帰は save/load の stale resurrection 禁止(theory/04)と直接衝突する。単調劣化+明示的再取得は、切断復帰の実務要求と証明可能性を両立させる唯一の形である。

**帰結**: 「寿命の長い外側の値に包まれて延命し、戻れる」という直感は理論と食い違う既知のずれとして mental-model/03 に明記し、診断メッセージでも同じ言葉で説明する。

**再考条件**: なし(凍結)。
