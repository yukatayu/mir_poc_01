# ADR-0017 — T0/G0 semantic-assertion profile v3

## Decision

Under ADR-0015 and PROPOSAL-020, adopt
`phase-governance/t0-g0` version 3 as defined in `plan/04`. It supersedes
ADR-0013 version 2 **only as the current T0 profile**. It does not alter the
accepted D1 cut, D2 adoption history, or D4 waiver.

Version 1 remains byte-preserved nonconforming historical evidence. Version 2
remains its valid historical `fail` artifact. Neither may be rewritten,
re-generated, re-pinned, or interpreted as v3 evidence.

## Profile and lifecycle separation

The profile is deterministic because it evaluates Git blobs at its declared
source revision and derives an ordered semantic-assertion artifact. A v3
`pass` is necessary evidence, not lifecycle action by itself. Only the M2
acceptance amendment below may cite its exact reproduced digest and then apply
`pass digest acceptance → G0-D3 acceptance → G0 exit → T1 entry`.

## Non-effects

Profile adoption does not claim SCN/C-static/C-runtime/C-distributed
conformance, proof or OBL completion, runtime implementation, I1 authorization,
public API/ABI/wire, deployment, or a change to the Constitution's guarantees.
