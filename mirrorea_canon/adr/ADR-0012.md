# ADR-0012 — 正本関係と改定手続き

**決定**: 本 canon がプロジェクトの唯一の規範的正本である。旧 repo `mir_poc_01` は LAB(実験場・evidence 置き場)であり、その specs/plan/report は「歴史的 evidence」として `LAB:specs/39` の形式で引用される。衝突時は canon が勝つ。規範の変更は、(1) `meta/proposals/` への起票、(2) 人間の決定、(3) 該当ファイル改定+ADR/CHANGELOG 追記、(4) `INDEX.json` 再生成、の一方向手続きのみ。AI エージェントは (1) と、決定済み事項の帰結の機械的展開・検証のみを行える(meta/agent-instructions)。

**理由**: 手詰まりの根本原因(決定主体の不在、evidence 最適化バイアス、文書エントロピー)への構造的対策。決定の所在を一箇所・一人に固定する。
