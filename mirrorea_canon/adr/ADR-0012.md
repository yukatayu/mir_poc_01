# ADR-0012 — 正本関係と改定手続き

**決定**: 本 canon がプロジェクトの唯一の規範的正本である。旧 repo `mir_poc_01` は LAB(実験場・evidence 置き場)であり、その specs/plan/report は「歴史的 evidence」として `LAB:specs/39` の形式で引用される。衝突時は canon が勝つ。規範の変更は、(1) `meta/proposals/` への起票、(2) owner decision、(3) 該当ファイル改定+ADR/CHANGELOG 追記、(4) `INDEX.json` 再生成、の一方向手続きのみである。ADR-0014 は program 外 research に、standing predicate を満たす可逆な L3 pre-registration を `working/` へ許す。L2 promotion は owner-authenticated trust anchor がない現在は fail-closed である。ADR-0015 は PROPOSAL-018 に記録された owner decision の範囲で、Mir Theory v0 / I1+ milestone consequence の evidence-gated integration を許す。これは Canon/LAB の正本関係又は owner-reserved conditions を変更しない。

**理由**: 手詰まりの根本原因(決定主体の不在、evidence 最適化バイアス、文書エントロピー)への構造的対策。決定の所在を一箇所・一人に固定する。
