# ADR-0010 — 検証の三線分離

**決定**: 検証は (1) 有限・宣言済み断片への決定可能 static checker、(2) 有限遷移系へ落とせる scenario の model-check、(3) checker 健全性・意味補題の proof 側線、の三線に分ける。checker は discharge しない義務を成功扱いせず、`ResidualObligation` として明示 carrier に残す。証明は Lean-first(Rocq/Coq+Iris は並行圧が強まった際の fallback family)。Mir ソース自体を証明言語にしない。full dependent type は first core に入れず、有限 index / refinement 断片(有限 poset・lattice・powerset・region preorder・capture set・単純資源上界)を first layer とする。

**理由**: 一本の checker への collapse も、何でも残余へ逃がすことも避け、operational readiness と証明可能性を両立させるため(LAB specs/19 の追認と蒸留)。

**再考条件**: OPEN-007 — prover の具体ブランド束縛・公開 verifier 契約は Gate 4 以降の later gate。
