# ADR-0008 — pre-M6 Surface grammar profile

## 2026-08-04 M1 alignment

ADR-0016 により、下記の grammar は **pre-M6 Surface profile** として保持する。
既存 LAB evidence と互換性候補の読み筋を失わせないが、Mir Theory v0 final grammar
を先取りして固定しない。M6 は shared model の後で、この profile と最小の有力代替を
比較して final bounded grammar を決める。carrier、relation/designated-evaluator
annotation、parser、public syntax はこの amendment だけでは選ばない。

**決定**(詳細は spec/02):

1. place-scope は `S { ... }`。`S[ ... ]` は不採用(`[]` は索引専用)。role-instance は `Role[binder] { ... }`。
2. 等価比較は `==`、不等は `!=`。**代入は `=`**。LAB Full-System-V1 の「`=` を等価に使う」流儀は廃止。
3. コメントは `//` 行 と `/* */` 塊。
4. handler は `when name(params) fails F1, F2 { ... }`。`fails` は「引き受ける失敗の宣言」であり、生成失敗 ⊆ 宣言 が静的義務。
5. fallback の Surface 形は **`chain` 宣言**(option 列を `>` で結び、辺に `@ lineage` 注記)。式レベル `fallback(x, y)` は Surface v0 に置かない。
6. `perform on/via`・`option`/`chain`(Core 形)・`try { } fallback { }`・`atomic_cut` は **Core companion 記法**として spec/04 附録に存置(LAB の D-030..D-036 系の継承)。

**理由**: LAB の Surface 線(P-SURF)で実証済みの読み味を採り、二系統あった文法(FSV1 と Surface)を一本化する。

**再考条件**: OPEN-005 — `chain` 宣言の表記は本 canon 中で最も調整が入りやすい箇所と予告する。OPEN-006 — `try/fallback` を Surface に昇格するかは Gate 2 で判断。
