# ADR-0005 — 権限は grant の系譜のみ

**決定**: 次はいずれも権限を与えない — role の自己申告、indexed state の key であること、locus 名・見かけの位置、runtime 種別、transport 接続、provider 名、package 名、署名(provenance であって semantic safety でない)。権限は admission verdict に発する capability grant の系譜のみが運び、使用時に(principal, role, 対象, epoch, incarnation, 必要 witness)の一致を検証する。stale な権限は load / rollback 後も復活しない。

**理由**: なりすまし・混同(auth を transport に潰す等)の防止をアーキテクチャで保証するため。

**帰結**: `player[Alice]` の key が Alice でも Alice に書き権限は生じない(theory/05)。認証・認可・membership・capability・witness を transport metadata に collapse しない(BND-005)。

**再考条件**: なし(凍結)。
