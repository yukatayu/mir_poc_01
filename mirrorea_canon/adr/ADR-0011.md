# ADR-0011 — 外界は typed adapter 境界

**決定**: Mir core は `stdin`/`stdout`/`stderr` 等の特権 I/O primitive を持たない。外界(console・HTTP・エンジン・センサ)は `ExternalAdapter<A,B>`(入出力 schema・effect/failure row・権限・観測 policy・境界種別を宣言)を通る。adapter 境界は transport(配送)と別物であり、auth/capability/witness/observation policy を transport metadata に潰さない。可視化・telemetry も情報を運ぶ効果として同じ規律に従う。

**理由**: 「effect-based OS-like substrate」という内側の解釈を保ちつつ、subsystem collapse と隠れ I/O を防ぐ(LAB specs/23・plan/12 の追認)。
