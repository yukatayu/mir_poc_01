# ADR-0015 - Owner-delegated Mir v0 / I1+ execution

Decision date: 2026-08-03

## Decision

PROPOSAL-018 の owner disposition を採用する。Mir Theory v0 と Mir I1+
deterministic reference system を完成させる Milestones 0--10 の範囲では、agent
orchestrator は Canon theory/spec/scenario/Gate/Phase/proof-ledger、Lean、Rust、tests、
conformance、governance、roadmap/status を、accepted Constitution と milestone
acceptance criteria に従って更新できる。

この scope では ADR-0014 の file-level reserved boundary と L3-only write route を
置き換え、変更内容・反証可能性・証拠・独立 review による bounded autonomy を用いる。
ADR-0014 はこの program 外の research に対する default route として残る。

各 milestone は一つの semantic frontier と原則一つの report を持つ。normative rule、
executable behavior、positive/negative evidence、formal evidence、独立 review、
validation、commit/push を閉じる前に次の semantic milestone へ移らない。

## Preserved invariants

- Canon is the only normative source; LAB remains evidence and implementation.
- Communication is a projection of checked meaning, not the starting API.
- Evaluation locus, authority origin, trigger, semantic form, and
  materialization remain separate information.
- No hidden communication, authority, effect, failure, information release,
  distributed transaction, stale resurrection, or patch mutation on rejection.
- World/Room/Avatar/Game remain domain or library vocabulary, never Core
  primitives.
- Static checking, bounded model checking, and proof remain separate assurance
  lines.

## Proof and review discipline

One independent reviewer tries to falsify each milestone. A correction cycle is
normally performed once; a second is allowed only for new material
counterevidence. `lean-proved` requires a compiled, trusted, non-placeholder
proof with checked axioms and theorem/implementation correspondence. Other
evidence is classified as `lean-stated`, `model-checked-bounded`,
`runtime-monitored`, or `intentionally-deferred`.

## Owner-reserved conditions

The owner remains the decision authority for changes to the North Star,
weakening safety/privacy guarantees, Core promotion of domain vocabulary,
mandatory introduction of an explicit v0 non-goal, irreversible final public
API/ABI/wire commitment, production deployment/external publication,
irreversible tied alternatives not ordered by project priorities, and actions
that risk current user data or secrets.

## Consequences

- `plan/02-operating-model` defines the milestone execution discipline.
- `meta/agent-instructions` defines the scoped write protocol.
- Current roadmap/status documents select exactly one critical path; historical
  plans and reports remain repository memory, not an active queue.
- Planner may write delegated planning/status/governance surfaces and validate
  them; production source remains implementer-owned unless explicitly
  delegated.
- Proof status may move without a second owner confirmation when the evidence
  conditions above are actually satisfied.

## Reconsideration

Reconsider when an owner-reserved condition is reached, repeated independent
review shows the bounded route cannot preserve an invariant, or the I1+ program
is complete and a new owner direction is needed.
