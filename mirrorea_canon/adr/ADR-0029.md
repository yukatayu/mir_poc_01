# ADR-0029 — SYS-3 checked-Core per-locus projection

Decision date: 2026-08-27

## Decision

Adopt PROPOSAL-032's crate-private pure projection boundary:

```text
CheckedSurfaceV0 + exact identity-bound logical locus inventory
  -> GlobalProjectionResult | ProjectionDiagnostics
```

The topology supplies loci only. It must exactly cover the checked static
environment plus Core-referenced loci and cannot supply communication,
authority, failures, handlers, schemas, or deployment mapping. The result is
canonical under input/topology ordering and owns placement-specific typed
checked fragments, so its direct consumer need not retain an AST or reparse
source.

`GlobalProjectionResult` contains the per-locus programs, generated
communication/effect/observation/persistence plans, source/Core/artifact
correspondence, current relation graph, static-versus-runtime-admission status,
and ADR-0028 ST/OW1 requirements. Static projection is not runtime admission;
residual-bearing artifacts stay blocked and residual-free artifacts still
await the sealed runtime seam.

Close-review amendment: the checked input must also contain the distinct
source-derived result-consumer edge created by the bounded provisional clause
`designated consume E.result at C`. It binds one explicitly named consumer to
an existing designated result and carries the result identity,
input/result frontiers, version, observation policy, policy stamp, and
same-consumer retry contract. It cannot be inferred from topology, schedule,
relation, or deployment. An undeclared or competing consumer is a typed static
failure; same-consumer retry returns the existing decided result without a new
semantic consume. This is a static SYS-3 requirement and a new SYS-4 endpoint
refinement obligation, not evidence of current M8 behavior. Legacy M8 rejects
the same delivery id with `AlreadyConsumed` and may consume a different id;
the accepted M10 duplicate-delivery baseline remains unchanged. SYS-4 must
provide the source/Core-bound carrier-side idempotent return or compatible
wrapper and actual positive/retry/competing-consumer endpoint tests before
claiming runtime correspondence.

## Placement and authority consequence

Same-owner RMW Core and state schemas remain only in the checked owner
artifact; the authority-origin locus receives a request invocation fragment.
Maintained relation Core remains an owner publication and consumer-local
projection, never an absolute-value stream or consumer mutation. Designated
remote state reads remain source-owner services and the designated expression
remains at its evaluator. An explicit designated-consume Core places a
consumer-only fragment at the named consumer and generates an
evaluator-to-consumer `DesignatedResultDelivery` edge without copying the
expression or raw input. Each generated edge directly references real source
and target fragments and carries checked identity, source/Core provenance,
typed effect/failure and lifecycle requirements without transferring or
minting authority.

Observation rows are future occurrence requirements with reference-only
redaction, not runtime observations. Persistence rows assign responsibilities
but perform no save/restore. Effect-handler planning remains source/Core-bound
to owner and designated services; it is not a generic provider registry.

## Relation boundary

Production projection accepts and preserves only the current checked
two-anchor primary -> fallback relation shape. A test-only typed extension
boundary demonstrates one finite source-bound deeper/shared dependency
pressure case and rejects cycles and foreign checked-program references. It
does not add ordinary-source nested relation semantics, mint semantic
dependencies, or establish an arbitrary-DAG theorem.

## Lifecycle consequence

SYS-3 is closed; SYS-4 in-process generated dispatch is the sole active
ADR-0026 milestone and SYS-5 is next. Theory remains T1. Broad PHASE-I1 exit and
official I2 entry/exit remain unaccepted: this decision generates static

architecture/04 full carrier freeze plus OPEN-026/027 remain unresolved.

## Non-effects and reconsideration

This decision does not claim runtime admission or dispatch, actual occurrence
or endpoint execution, durable persistence, patch execution, production
relation DAGs, optimal/deployment placement, public API/ABI/wire/JSON, real
transport, broad lifecycle acceptance, or a general determinism/completeness/
owner-preservation/coherence theorem.

It authorizes exactly one bounded, non-final internal Surface-v0 clause and its
AST/M6/M7 checked Core edge. It does not freeze final/public grammar, add
multi-consumer semantics, or select any public API/ABI/wire.

Reconsider only for a reproducible selected-fragment nondeterminism, missing
or extra checked-Core-derived edge, owner/evaluator relocation, provenance or
authority minting, a SYS-4 need to reconstruct semantics from source, or a
later source-derived finite relation extension that cannot use the retained
acyclic boundary conservatively.
