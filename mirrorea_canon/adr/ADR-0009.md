# ADR-0009 — ソース正本

**決定**: 意味の正本は `.mir` ソースファイルである。`package.mir.json` その他のパッケージ成果物・Core IR ダンプは、parse→check→elaborate の産物または互換 helper であり、逆方向は移行補助にすぎない。release・runtime・devtools の evidence は常にソース起点の系譜を持つ。

**理由**: 「普通に書いたソースが意味を持つ」という軸の直接の帰結。生成物を正本にすると、diagnostics の span と patch pipeline が壊れる。
