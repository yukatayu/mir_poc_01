# ADR-0006 — patch は eval でない

**決定**: 実行中セッションへの source patch は必ず pipeline(parse → typecheck → elaborate → 互換性 → capability/admission → HotPlugRequest → Verdict → activation cut)を通る。rejected / deferred は runtime を一切変異させない(lifecycle 行のみ)。activation は admission 時に検査した membership / witness frontier に束縛され、frontier がずれたら reject/defer。patch の自己権限付与・未宣言 failure・redaction 弱化・確定済み prefix の書換えは拒否。開発用でも直接 eval は禁止。

**理由**: hot-plug は本プロジェクトの capstone であり、DAG 規律・権限・cut の全てが揃って初めて安全になる。eval を一度でも許すと全定理が崩れる。

**再考条件**: なし(凍結)。
