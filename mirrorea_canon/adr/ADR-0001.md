# ADR-0001 — World は primitive でない

**決定**: `World` / `Room` / `Avatar` / `Game` 等の空間語彙は S5(ドメイン/ライブラリ)の語彙である。core 理論(S1)は locus・state・authority・cut などの中立語彙のみを持つ。文法上も予約語にしない。

**理由**: World は相対的である(world の上に world が載る、shard・portal で分割される)。絶対的な root を core に置くと、存在 DAG の一般性と patch による拡張性を壊す。

**帰結**: canon の全例で `World` はただの宣言済み place 名。LAB の clean-near-end 系サンプルと `mir_hilight.html` の `world` 擬似予約語は歴史的語彙とする(GLOSSARY 旧語彙対応)。

**却下した代替**: World を組み込み root にする案(初期化が簡単になるが、相対性・多層性と矛盾)。

**再考条件**: なし(凍結)。
