MirCore Surface/Core sketch has no corresponding Surface form or elaboration
rule. The existing `textual_alpha` parser is LAB evidence, not a canonical
Surface-to-Core importer, so this observation has no current non-reserved

boundary: a later canonical package must explicitly decide whether `return` is
in the exact v0 fragment and, if it is, state its Core/elaboration treatment.
