# plan/165 - post-WRK-0007 candidate selection

## Role and authority

This is LAB repository memory. `mirrorea_canon/` remains authoritative for
theory, OBL status, Gates, Phases, contracts, and every semantic selection.
This selection does not open a WRK, alter a Canon statement, or make a proof
claim.

## Trigger and method

After WRK-0007 retained the OBL-001 Result/write enumeration countermodel, the
remaining statement lanes were reread against their Canon anchors, plan/156,
WRK-0001 through WRK-0007, and current explanatory boundaries. Read-only
planner and reviewer passes plus temporary Oracle reviews challenged both a
new OBL-001 predicate-disconnection model and three diagnostic candidates.

## Current selection

**No new L3 record is selected.** This is a LAB priority disposition, not an
ADR-0014 prohibition. The existing lanes remain available for a future
source-grounded structural mismatch with a distinct adverse outcome.

1. Another OBL-001 model that disconnects request/result predicates is a
   duplicate of T-RESEARCH-001's unconstrained-predicate finding and WRK-0007's
   more specific Result/write enumeration gap. Resolving it selects the
   reserved Core/result or request bridge.
2. An OBL-025 model with `CoveredLine1RepairCase = false` is not new evidence:
   `plan/87` explicitly says that this guard keeps the compile-check-only LAB
   draft from claiming all Line-1 families. The Line-1 fragment boundary is an
   existing open formalization question, not an unobserved draft defect.
3. An OBL-025 model that separates the existential metadata tuples in
   `EligibleSingleEditRepair` and `SuggestionCoversWitness` is a possible
   finite LAB formula experiment, but Canon does not require that particular
   tuple identity. It is a specialization of T-RESEARCH-027's already-recorded
   coupled rejection / repair / diagnostic-realization boundary, not a distinct
   Canon-facing branch.
4. An OBL-024 model with one sound reported projection and an additional
   spurious projection would require interpreting the predicate representation
   as a non-functional Diagnostic field carrier. The Canon diagnostic record
   direction does not select that LAB representation or a functionality law;
   T-RESEARCH-026 already records the broader association/replay boundary.

## Reopen conditions

Re-run ADR-0014 triage only when an existing Canon/LAB source shows a genuinely
new mismatch with distinct positive and adverse outcomes, an owner/canon action
opens a previously reserved proof-facing boundary, or an existing documented
lane supplies a reproducible falsifier without a helper, schema, runner, or
public-interface addition.

## Non-claims

This does not say that Canon OBL-024/025 are false, that the LAB drafts are
proofs, or that the listed abstract predicates define final Diagnostic, repair,
Core/result, request, equality, or field-functionality semantics. It does not
change `theory/11`, an OBL, a Gate, a Phase, runtime behavior, or public
readiness.
