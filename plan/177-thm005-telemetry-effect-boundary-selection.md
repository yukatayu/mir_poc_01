## Selected question and stop line

The proposed working question is only this: can a finite experiment-local
model contain two configurations that agree on modeled low state, yet export
different observer-safe rows solely because a declared telemetry effect depends
on modeled high state? The positive control must use a telemetry source that is
occurrence-derived or explicitly low-observationally determined; its exports
must agree.

The adverse control, if it compiles, establishes only an **experiment-model
premise boundary**: THM-005-style reasoning needs a demonstrated
low-observational dependency condition for the telemetry source in that model.
It does not refute THM-005, choose a telemetry semantics, or resolve the
apparent wording relation with BND-008. The record must freeze rather than
repair if the model requires a new effect primitive, label lattice,
declassification rule, event/export ABI, pipeline semantics, helper, schema,
CI/Make surface, or production behavior.
