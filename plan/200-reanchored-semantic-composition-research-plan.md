## 自走する順序

### R0 - Common-cut re-anchor

1. current Canon cut を pin し、C0--C7 が利用する literal fact を source/section/digest/
   authority-class/non-claim として manifest 化する。
2. historical WRK の evidence cut と current fact を混同しない。
3. proposal detail、scenario notation、current grammar/Core を区別する。

R0 の falsifier は、同一 fact が source cut によって変わる、又は authority class が
literal source だけでは決まらない場合である。その場合は downstream 結論を止める。

### C1/C6 - Independent candidate families

C1 は snapshot/evaluation locus/read-modify-write fusion を選ばず、各 candidate が
WRK-0024 lost-update trace をどう admit/reject/prevent するかだけを測る。C6 は

### C3/C5/C4 - Value flow and occurrence facets

1. C3 は V1/R1 に従い、typed pending control、one receipt to one resumption、failure
   suppression、linear `Delta` を candidate-local に検査する。
2. C5 は conditional A2 を先に検査する。verdict-time membership/grant/witness issuance
   が一体であり、named facet で既存 causal edges を構成でき、rejection residue が無い
   場合だけ A2 family を継続する。別 failure/observable/schedule が出れば A1 successor
   を要求する。
3. C4a は SW1 の service/mutation/validation facet を一 occurrence に載せる local
   model。C4b は C2 binding/replay、C5 facet、C3 value flow と統合する。validation と
   mutation の間に schedulable phase が必要なら SW1 を修理せず decomposed successor を
   要求する。

### C7 - Ergonomic inference

C7 は全候補の explicit semantics が揃ってからだけ実施する。省略は、(a) normative
input から一意、(b) elaborated artifact が fact と根拠を復元、(c) owner の explicitness
mandate に反しない、の全てを満たす場合のみ候補になる。final store の一致だけでは不足で、
value/receipt/pending/occurrence/authority/failure/history/save-load の観測が一致しなければ
reject する。

scalar/default、semantic request/pending/grant/witness identity、read materialization、
snapshot/evaluation choice、dynamic authorization verdict は source inference にできない。
fresh identity は source omission の推論ではなく、明示的に生成・保持すべき semantic fact
である。
