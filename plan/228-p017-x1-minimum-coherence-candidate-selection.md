# Plan 228: P017 X1 Minimum Coherence Candidate Selection

## Role and authority

This is LAB candidate-selection memory after the owner accepted P017 X1 and
after Plan 227 fixed the choice-neutral review boundary. `mirrorea_canon/`
remains normative. This plan selects neither a Canon relation schema nor a
`Config`/`SaveObject` field, request/result/receipt carrier, occurrence kind,
transition, dynamic failure member, Core form, source grammar, runtime,
transport contract, theorem, OBL, scenario, Gate, Phase, implementation, or
public behavior.

The selected package is a reversible ADR-0014 L3 experiment only. It may test
whether one candidate-local minimum relation-envelope presentation keeps every
P017 required row explicit at one pinned cut. A compatible result is not a
claim that Canon has been satisfied or that a positive model is adopted.

## Current cut and selection criterion

Plan 225 closes further P017 X1 fixture-only detector expansion. Plan 226
rejects the proposed restore-quantifier countermodel as duplicate evidence.
Plan 227 consequently leaves one distinct research question: whether the
already accepted X1 relation-state family admits a **single, erasable minimum
coherence presentation** whose rows remain separate without selecting a shared
carrier or lifecycle for later ordinary design.

P017 authorizes an existing-LAB-lane L3 record to define and falsify a minimum
model. It requires the explicit relation component, dynamic domain,
unique pending binding, M1/provenance, owner branch, typed result/failure,
receipt/use, causal, observation, save/load, and source-boundary rows to be
tested with a decisive falsifier and bounded proof argument, countermodel, or
explicit stop result. It also requires the package to stop at a newly needed
Core primitive, source identity, transport carrier, public contract, causal
generator, occurrence kind, or `G_e` row.

The selection criterion is deliberately stricter than a new finite label
table: the candidate needs an independent consumer in the later P017 ordinary
integration review, a row-specific falsifier, an existing documented LAB lane,
and a presentation that can be discarded without becoming a schema or runtime.

## Selected candidate boundary

The next record may use the P017-permitted **rejection-external** variant as a
LAB hypothesis: a rejected raw delivery candidate is outside the semantic
exchange transition system and leaves receipt-pending, owner-result
availability, and the accepted-consumption budget unchanged. This does not
close OPEN-010, introduce a requester failure member, or specify a real
adapter/rejection mechanism.

It may claim no observer surface. That is an explicit no-observation scope,
not a theory/07 model and not a storage-based visibility shortcut.

The exact candidate-local test labels may distinguish: hidden residence;
authority collapse; branch overlap; receipt/use collapse; consumption
multiplicity; causal gap; restore breach; observation leak; reserved surface
required; and required row open. They are labels in one disposable research
record, not a global type, schema, predicate vocabulary, or lifecycle.

The candidate does not reopen the X1 family choice. P017 has already selected
an explicit relation-valued exchange component anchored by `q` in current or
admissibly restored history. History-only and nominal-identity alternatives
remain outside this package.

## Required pre-registration and stop line

Before any source is materialized, create one new L3 record in
`mirrorea_canon/working/` that pins P017, ADR-0014, the direct theory
constraints, and Plans 225--227 at the selection cut. Its preregistration must
state its narrow question, status quo, alternative, expected falsifier,
non-effects, rollback/reopen trigger, permitted LAB locations, and the fact
that no result exists yet.

After that registration is committed and pushed, the only possible source is
one Markdown-held Lean block in a new file under `plan/`. It must be extracted
to a disposable temporary file and validated with `lean --trust=0`. It must
provide a bounded proof argument, countermodel, or explicit stop result for
each P017 required row on which it relies. The package stops rather than
repairs the artifact when it needs any reserved surface, a shared schema,
unannounced primitive, runtime behavior, source-level correlation, transport
semantics, global identity, liveness/fairness, or a Canon status claim.

runtime, test helper, schema, CI/Make surface, or public interface. It does not
alter the scoped no-candidate result for the fixture-only or restore-quantifier
